# Data Structure Algorithms and Applications (CT-159)

A practical repository featuring C++ implementations, lab solutions, and coursework assignments aligned with the **Department of Computer Science and Information Technology** curriculum.

---

## 📌 Syllabus & Topics Covered

This repository tracks core algorithmic concepts and data structure implementations taught across the semester:

* **Linear Data Structures & Sorting:**
  * Searching (Linear & Binary Search) and Abstract Data Types (ADTs)
  * Singly, Doubly, and Circular Linked Lists
  * Stacks, Recursion, Queues, Circular Queues, and Deques
  * Elementary & Advanced Sorting (Bubble, Insertion, Selection, Merge Sort, Quick Sort)

* **Trees & Hierarchical Structures:**
  * Binary Trees, Properties & Traversals
  * Binary Heap, Heap Sort & Priority Queues
  * Binary Search Trees (BST) & Self-Balancing AVL Trees

* **Graphs & Hashing:**
  * Graph Representations, Traversals (BFS/DFS), and Shortest Path Algorithms
  * Minimum Spanning Trees (MST), Topological Sorting & Graph Algorithms
  * Hashing, Hash Functions, Collision Resolution Techniques & Rehashing
